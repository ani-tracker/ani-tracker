# Stitch UI 全量改版人工验收清单

更新时间：2026-07-19

## 1. 验收准备

- [ ] 当前分支为 `master-stich-ui`，执行 `pnpm.cmd dev` 后应用可正常启动且无白屏。
- [ ] 使用可删除的测试追番和测试下载任务，避免破坏正式数据。
- [ ] AniBT 只使用单一稳定网络出口；不使用代理池、IP 轮换或模拟 Cloudflare Cookie。
- [ ] 准备视口 `1440x900`、`1024x768`、`768x1024`、`390x844`，并保留控制台与主进程日志。

## 2. 全局应用壳与导航

- [ ] `1440x900` 显示 224px 完整侧栏；导航固定，主内容独立滚动。
- [ ] `1024x768` 显示 72px 收缩侧栏；图标 Tooltip、当前项、未读数均可识别。
- [ ] `768x1024` 与 `390x844` 使用顶部菜单和 320px 左侧 Sheet，关闭后焦点回到菜单按钮。
- [ ] 首页、新番发现、我的追番、资源搜索、下载队列、提醒中心、下载源、设置均可切换。
- [ ] 页面切换后无双滚动条、非预期横向滚动、内容跳位、文字遮挡或浮层越界。

## 3. 主题与自定义调色

- [ ] 浅色、深色、跟随系统三种模式切换即时生效，重启后保持选择。
- [ ] 系统模式下切换 Windows 明暗外观，应用同步变化且无明显闪屏。
- [ ] 自定义主题可复制、编辑颜色与圆角、保存、切换和删除。
- [ ] 导入 `docs/image-palette-example.ani-theme.json` 后可预览并应用。
- [ ] 导出已导入主题，再次导入后颜色、名称、圆角和明暗令牌一致。
- [ ] 导入非法、超大或含未知字段的主题时显示错误，当前主题不被覆盖。
- [ ] 浅色与深色下正文、次要文字、焦点环、Toast、Dialog 和 Sheet 均清晰可读。

## 4. 页面布局与长内容滚动

- [ ] 首页摘要、今日更新、待处理、下载与最近完成信息完整，局部失败不导致整页空白。
- [ ] 新番发现的季度图鉴与时间表可切换；时间表仅内容区横向滚动。
- [ ] 我的追番长列表、规则 Sheet、资源 Sheet、任务 Sheet 均可滚动到底；标题与底部操作区固定。
- [ ] 资源搜索长标题自动换行，筛选、来源错误、分页和下载按钮不互相遮挡。
- [ ] 下载队列进度、速度、状态和展开文件列表更新时不引发布局跳动。
- [ ] 下载源和设置长页面可滚动到最后一项，顶部导航或分区导航保持可用。
- [ ] 提醒中心的筛选、时间分组、全部已读和清空确认流程可完成。

## 5. 核心业务回归

- [ ] 新增、编辑、移除追番均成功；破坏性操作必须二次确认。
- [ ] 单集规则、默认字幕组、分辨率、编码、位深、字幕语言与目录偏好可保存。
- [ ] 资源搜索、来源绑定、批量下载和单条下载可完成，部分来源失败时保留成功结果。
- [ ] 下载任务暂停、继续、删除、文件选择、播放和定位文件可完成。
- [ ] 下载源启停、代理、采集间隔、凭据和立即同步可保存，重要结果进入提醒中心。
- [ ] 真实 qBittorrent 模式下添加任务后显示真实 hash，不出现永久占位任务。
- [ ] 远程 PWA 只显示授权页面，不出现下载源、设置、本地路径或桌面危险操作。

## 6. AniBT 限流、缓存与熔断

- [ ] AniBT 采集间隔输入框最小值为 3000ms，输入更小值保存后仍规范为 3000ms。
- [ ] AniBT 适配器和同域追番 RSS 不并发请求；连续请求实际间隔不少于 3 秒。
- [ ] 正常访问时请求包含常规 `User-Agent`、`Accept`、`Accept-Language`，真实网络返回 200。
- [ ] 同一查询并发触发时只访问源站一次，其余调用复用响应。
- [ ] 完结作品首次搜索后关闭并重启应用，再以相同来源、筛选和绑定搜索；7 天内日志显示命中查询缓存，且不发起 AniBT 网络请求。
- [ ] `forceRefresh` 仅在用户明确刷新时绕过缓存，并仍受 3 秒同域限流约束。
- [ ] 若真实网络自然返回 403，界面显示熔断提示；保护期内立即重试不得发起源站请求。
- [ ] 403 第 1/2/3 次失败分别进入 10/20/30 分钟保护；到期后只允许一个半开探测。
- [ ] 429 遵循 `Retry-After`，并按 1/5/15/30 分钟逐级保护。
- [ ] 熔断状态在应用重启后继续生效，成功探测后失败次数和保护截止时间清零。

说明：不要为了人工验收主动高频请求 AniBT 或诱发 Cloudflare 403。403/429 时间序列、半开单探测和跨重启状态已由自动测试覆盖；人工只验证自然异常下的可见反馈。
