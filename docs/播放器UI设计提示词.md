# Ani Tracker 响应式播放器 UI 设计与前端原型

你无需访问任何现有项目或仓库。请完全依据以下信息，直接生成一套高保真、可交互、响应式的播放器 UI。不要反问需求，不要生成营销页。

## 一、项目背景

产品名称：Ani Tracker。

这是一个本地桌面追番工具，用于新番发现、追番管理、资源搜索、BT 下载、媒体文件扫描和视频播放。

播放器存在两种运行环境：

1. PC 桌面端：运行在 Tauri 独立播放器窗口中，通过平台 libVLC 播放本地媒体文件。
2. 移动远程端：运行在手机浏览器中，通过局域网播放 PC 上的媒体流。

播放器需要支持：

- 原文件直接播放。
- HLS 实时转码。
- 原文件无法解码时自动切换实时转码。
- ASS、VTT 多轨字幕。
- 字幕开关和字幕轨道切换。
- 播放速度切换。
- 画中画。
- 全屏和网页全屏。
- 上一集、下一集。
- 同一番剧播放列表。
- 播放进度展示与恢复。
- 播放达到90%后标记已看。
- 当前视频结束后自动播放下一项。
- 移动远程端可调用设备本机播放器。
- 加载、缓冲、失败、重试和空状态。

本次只设计播放器页面，不包含应用首页、侧边栏、底部导航、下载管理或设置页面。

## 二、技术环境

如果生成代码，请使用：

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui，New York 风格
- Lucide React 图标
- Sonner Toast
- ArtPlayer 播放器容器
- HLS.js 播放 HLS 流
- pnpm

代码需要能作为独立 UI 原型运行，使用 Mock 数据，不连接真实后端。

不要重新实现视频解码器。提供一个可挂载 ArtPlayer 的视频容器；没有真实视频源时，使用深色媒体占位画面模拟播放器。

## 三、设计方向

整体风格为“Anime Editorial 工具界面”：

- 克制、紧凑、专业、信息优先。
- 有动漫内容氛围，但不能做成动漫视频网站首页。
- 正文基准字号14px，辅助信息12px。
- 标题清晰但不过度放大。
- 控件使用小圆角。
- 卡片和媒体容器圆角不超过8px。
- 海报固定2:3比例。
- 视频区域使用纯黑或媒体黑背景。
- 普通内容区域使用主题语义颜色。
- 支持浅色、深色和跟随系统。
- 允许主题层定义颜色，业务组件不得直接写死颜色。

颜色语义：

- `background`：页面背景。
- `foreground`：主要文字。
- `primary`：主要命令和当前播放焦点，默认视觉倾向珊瑚红。
- `muted`、`muted-foreground`：辅助区域和次要信息。
- `accent`：悬停、选中和信息焦点。
- `border`：边界和分隔。
- `destructive`：播放失败和危险操作。
- 成功、警告、错误状态必须同时显示图标或文字，不能只靠颜色表达。

禁止：

- 营销型 Hero。
- 大面积装饰渐变。
- 玻璃光球、霓虹光晕。
- 夸张圆角和胶囊化布局。
- 页面区块层层嵌套卡片。
- 在视频上添加永久暗色滤镜。
- 使用背景图片代替真实信息层级。
- 把所有按钮都放进彩色圆形容器。
- 在移动端塞入完整桌面控制栏。
- 用说明文案解释用户应该如何操作。

播放器控制层可以使用功能性半透明纯色遮罩和轻微模糊，但不要使用装饰性渐变。

## 四、响应式视口

必须分别设计并验证：

- 手机竖屏：390×844。
- 手机横屏：844×390。
- 平板竖屏：768×1024。
- 中等桌面：1024×768。
- 标准桌面：1440×900。
- PC 独立播放器默认窗口：1280×720。
- PC 最小播放器窗口：960×540。

任何尺寸不得出现横向溢出、按钮重叠、字幕被控制栏遮挡或内容无法访问。

## 五、手机竖屏布局

手机竖屏采用“上方播放、下方内容”的结构。

### 1. 页面结构

页面占满 `100svh`，不显示应用侧栏、顶部导航或底部导航。

上方为播放器区域，下方为番剧信息和播放列表。播放器保持16:9，不裁切视频；在较高手机上不要强制把视频拉伸到屏幕一半。

推荐层级：

1. 视频播放器。
2. 当前播放摘要。
3. 番剧简介。
4. 分隔线。
5. 播放列表标题。
6. 播放列表内容。

播放器可吸附页面顶部，下方内容独立纵向滚动。固定区域不得遮挡列表最后一项。

### 2. 视频播放器

播放器宽度100%，视频使用 `object-fit: contain`，背景为媒体黑。

默认隐藏复杂控制，点击视频后显示控制层。

顶部控制层：

- 返回按钮。
- 当前番剧标题，单行截断。
- “第08集”等当前集数。
- 播放列表按钮。
- 更多操作按钮。

中部控制层：

- 快退10秒。
- 大号播放/暂停。
- 快进10秒。

底部控制层分两行：

第一行：

- 可拖动播放进度条。
- 已缓冲进度。
- 当前播放位置提示。
- 拖动时显示目标时间。

第二行：

- 当前时间/总时长。
- 字幕按钮。
- 倍速或设置入口。
- 横屏按钮。
- 全屏按钮。

由于手机宽度有限，清晰度、转码模式、字幕轨道、倍速和外部播放器等次要操作放入带标题的 Drawer，不要在视频底部堆满按钮。

控制层在播放且无操作3秒后隐藏。暂停、缓冲、错误、Drawer 打开时保持显示。

### 3. 当前播放摘要

视频下方直接显示当前播放信息，不使用装饰卡片包裹整个区域。

内容包括：

- 2:3小海报，建议64×90px左右。
- 中文标题。
- 日文或原始标题。
- 当前集数与单集标题。
- “正在播放”Badge。
- 分辨率Badge，例如1080P。
- 视频编码，例如HEVC。
- 当前字幕组。
- 观看进度，例如“已观看 18:42”。

长标题允许换行两行；极端长度才截断，并提供完整标题访问方式。

### 4. 番剧简介

显示简短剧情简介，默认最多三行。

使用 Collapsible 实现“展开简介/收起简介”。展开后自然推开下方列表，不能覆盖播放列表。

简介旁可显示少量元数据：

- 2026年。
- TV。
- 全12集。
- 评分8.4。
- 连载中或已完结。

元数据使用 Badge 或紧凑文本，不要设计成大面积数据卡。

### 5. 播放列表

简介和播放列表必须同时存在于下半区，不能使用 Tabs 将其中一个完全隐藏。

列表标题：

- “播放列表”。
- 已完成视频数量，例如“8/12”。
- 可选的排序菜单。
- 快速滚动到当前集按钮。

每个列表项显示：

- 集数编号，例如“08”。
- 单集标题；没有标题时显示清理后的文件名。
- 分辨率、视频编码、字幕、时长或文件大小。
- 当前观看进度。
- 已看、未看、播放中、未下载等文字状态。
- 当前播放项显示播放图标和“正在播放”Badge。
- 已看项显示完成图标。
- 有进度但未看完时显示细进度条。

列表项最小高度56px，触控目标不小于44×44px。

点击当前项不重复创建播放会话；点击其他项立即切换并保持页面位置合理。切换后当前项自动滚动到可见区域。

下方至少应在390×844视口中看到2至3个播放列表项，让用户明确知道页面可以继续滚动。

## 六、手机横屏布局

手机横屏时进入完全沉浸式播放界面：

- 视频占满 `100svh` 和全部可用宽度。
- 隐藏番剧简介、海报和页面内播放列表。
- 视频保持原始比例，不裁切画面。
- 使用黑色留边。
- 适配刘海、圆角屏和安全区域。
- 控制栏不能进入 `safe-area-inset-*` 范围。

顶部控制层：

- 返回竖屏或退出按钮。
- 当前番剧标题。
- 当前集数。
- 上一集。
- 下一集。
- 播放列表。
- 锁定控制。
- 更多操作。

中部：

- 快退10秒。
- 播放/暂停。
- 快进10秒。

底部：

- 全宽时间轴。
- 当前时间/总时长。
- 字幕。
- 倍速。
- 播放模式。
- 画中画。
- 全屏退出。

操作停止3秒后隐藏顶部和底部控制层。点击视频重新显示。

播放列表使用右侧 Sheet 打开，宽度约屏幕的38%至44%，但至少能清楚显示集数和标题。极窄横屏设备可改用底部 Drawer。

Sheet 必须包含：

- SheetTitle。
- 当前番剧名。
- 视频数量。
- 可滚动列表。
- 当前集高亮。
- 明确关闭入口。

打开播放列表时视频暂停策略保持原状，不要自动暂停。

支持：

- 单击视频显示或隐藏控制层。
- 双击左侧区域快退10秒。
- 双击右侧区域快进10秒。
- 双击中部播放或暂停。
- 旋转前后保持当前时间、音量、字幕和播放状态。
- Orientation API 不可用时仍能通过普通全屏正常使用。

## 七、平板竖屏布局

768×1024下：

- 顶部仍为16:9播放器。
- 下方可使用两列布局。
- 左列约40%，显示海报、标题、元数据和简介。
- 右列约60%，显示播放列表。
- 当可用宽度不足时自动退回手机单列结构。
- 不允许出现桌面侧栏或应用导航。

## 八、PC桌面端布局

PC端默认以独立横屏播放器窗口打开：

- 默认尺寸1280×720。
- 最小尺寸960×540。
- 窗口内容默认全部用于视频播放。
- 不默认显示番剧详情和播放列表。
- 视频使用 `object-fit: contain`。
- 任何比例的视频都不能被裁切。
- 留白区域统一使用媒体黑。

### 1. PC顶部控制层

顶部左侧：

- 返回或关闭播放器。
- 番剧标题。
- 当前集数和单集标题。

顶部右侧：

- 上一集。
- 下一集。
- 番剧信息。
- 播放列表。
- 用外部播放器打开，仅在能力可用时显示。
- 隐藏控制栏。
- 关闭播放器窗口。

可显示紧凑状态Badge：

- 原文件直传。
- 实时转码。
- 3条字幕。
- 总时长24:18。

不要让状态Badge挤压标题；空间不足时优先隐藏次要状态。

### 2. PC中部控制

暂停或鼠标移动时，可显示：

- 快退10秒。
- 大号播放/暂停。
- 快进10秒。

播放中不需要永久显示中部按钮。

### 3. PC底部控制层

第一行：

- 播放进度。
- 缓冲进度。
- 拖动时间提示。
- 当前章节标记预留能力。

第二行左侧：

- 播放/暂停。
- 上一集。
- 下一集。
- 当前时间/总时长。
- 静音。
- 音量Slider。

第二行右侧：

- 字幕。
- 倍速。
- 画面比例。
- 原文件/实时转码。
- 画中画。
- 播放列表。
- 网页全屏。
- 系统全屏。

窗口宽度不足时，将次要操作收进 DropdownMenu，禁止控制栏换行覆盖字幕。

### 4. PC播放列表

点击播放列表后，从右侧打开约380至420px的 Sheet。

Sheet结构：

- 固定头部。
- SheetTitle“播放列表”。
- 当前番剧名和视频数量。
- 中间 ScrollArea。
- 当前项自动定位。
- 列表底部不得被窗口边缘遮挡。

列表项显示：

- 集数。
- 单集标题或文件名。
- 分辨率。
- 视频编码。
- 文件大小。
- 时长。

当前项使用 `secondary` 或语义选中背景，并同时提供播放图标、Badge和 `aria-current`。

### 5. PC番剧信息

点击信息按钮后使用右侧 Sheet 展示：

- 海报。

不要同时打开信息Sheet和播放列表Sheet。

## 九、播放器设置面板

设置面板在手机使用 Drawer，在PC使用 DropdownMenu、Popover或Sheet。

设置项包括：

### 播放模式

使用 ToggleGroup：

- 不转码。
- 实时转码。

当前模式必须清晰可见。

原文件播放失败时：

1. 清除当前错误。
2. 自动切换实时转码。
3. 使用 Toast 提示“原文件无法播放，正在切换实时转码”。
4. 转码仍失败时显示错误状态。

### 字幕

显示：

- 关闭字幕。
- 默认字幕。
- 每条字幕的名称。
- ASS或VTT类型。
- 当前选中标记。
- 字幕偏移调整入口。

无字幕时显示“无可用文本字幕”，不要展示空菜单。

### 倍速

提供：

- 0.5×
- 0.75×
- 1.0×
- 1.25×
- 1.5×
- 2.0×

当前倍速显示在按钮上；1.0×时可简写为“倍速”。

### 画面比例

提供：

- 默认。
- 16:9。
- 4:3。
- 填充。
- 适应窗口。

默认模式不得裁切视频。

### 外部播放器

仅移动远程环境且检测到受支持播放器时显示：

- “用本机播放器打开”。
- 准备播放地址时显示Spinner和禁用状态。
- 成功后Toast提示已请求打开。
- 失败后Toast展示原因。
- 调起失败后恢复原播放器此前的播放状态。

## 十、交互规则

- 播放器获得键盘焦点后才响应快捷键。
- 空格：播放/暂停。
- 左右方向键：快退/快进5秒或10秒。
- 上下方向键：调整音量。
- M：静音。
- F：全屏。
- Esc：退出全屏或关闭当前浮层。
- P：上一集。
- N：下一集。
- L：打开或关闭播放列表。
- C：字幕开关。

鼠标、触摸或键盘活动应重新显示控制栏，并重置3秒隐藏计时。

播放暂停、播放失败、加载中、播放列表打开时，不自动隐藏控制栏。

进度条拖动时：

- 暂停自动隐藏计时。
- 显示目标时间。
- 松开后跳转。
- 跳转成功后恢复此前播放状态。

播放结束：

- 将观看进度标记为100%。
- 存在下一项时自动播放下一项。
- 不存在下一项时显示播放完成状态，并提供“重新播放”和“返回播放列表”。

## 十一、状态设计

至少生成以下状态：

### 1. 初始加载

- 保持最终播放器尺寸。
- 视频区域使用Skeleton或深色占位。
- 中央显示Spinner和“正在准备视频”。
- 禁用不可用控制。

### 2. 缓冲

- 保留当前画面。
- 中央显示Spinner。
- 控制栏仍可呼出。
- 不使用整页白色遮罩。

### 3. 暂停

- 显示中央播放按钮。
- 控制栏保持可见。
- 不添加覆盖整张画面的暗色滤镜。

### 4. 播放失败

使用 Alert 展示：

- 标题。
- 可理解的失败原因。
- 重试按钮。
- 切换实时转码按钮。
- 关闭播放器按钮。

保留可用的番剧和播放列表数据，不能退化为纯白屏。

### 5. 自动转码

- Toast提示正在切换。
- 播放模式Badge变为“实时转码”。
- 会话创建期间显示加载状态。
- 不重复无限切换。

### 6. 无字幕

- 字幕按钮显示不可用状态。
- Tooltip或菜单内显示“无文本字幕”。
- 不展示空列表。

### 7. 空播放列表

使用 Empty 组件：

- 标题“没有可播放视频”。
- 描述“当前番剧暂时没有已完成的视频文件”。
- 提供关闭或返回操作。

### 8. 当前任务不存在

使用错误状态展示：

- “播放任务不存在或已被删除”。
- 关闭播放器。
- 移动端可返回应用首页。

## 十二、shadcn/ui组件要求

优先组合现有组件，不要手写已有组件的替代品：

- Button：播放命令和图标操作。
- Slider：进度和音量。
- Badge：播放状态和媒体规格。
- Separator：区块分隔。
- ScrollArea：播放列表。
- Sheet：PC和横屏播放列表、番剧信息。
- Drawer：手机设置面板。
- ToggleGroup：播放模式等少量互斥选项。
- Collapsible：番剧简介。
- DropdownMenu：更多操作。
- Tooltip：桌面图标解释。
- Alert：播放错误。
- Skeleton：加载占位。
- Spinner：缓冲和进行中状态。
- Empty：无可播放视频。
- Progress：列表中的观看进度。
- Sonner Toast：短暂反馈。

组件规则：

- Sheet、Drawer必须包含可访问标题。
- 图标按钮必须有 `aria-label`。
- 桌面不熟悉的图标按钮必须有Tooltip。
- 图标使用Lucide React。
- Button内图标使用组件规范，不手工设置互相冲突的尺寸。
