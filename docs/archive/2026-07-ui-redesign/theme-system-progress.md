# 主题系统专项计划进度表

> 历史归档：本文保留专项执行进度，当前主题能力以 `src/shared/theme.ts` 和 `docs/progress.md` 为准。

最近更新：2026-07-18

## 专项目标

- 第一阶段提供 `跟随系统`、`浅色`、`深色` 三种外观模式，默认跟随系统。
- 将颜色、圆角、阴影、字体和信息密度收敛为语义设计令牌，保证 shadcn/ui 组件统一消费。
- 第二阶段支持内置主题包、主题包导入导出和用户自定义，同时保持页面结构、可访问性与跨平台一致性。
- Windows 为首要桌面验收平台；macOS 保持接口兼容；远程 Web/PWA 使用当前设备的独立外观偏好。

## 核心边界

| 决策项 | 方案 |
| --- | --- |
| 外观模式与主题包 | `themeMode` 控制明暗模式，`themePackId` 控制视觉风格，两者独立保存 |
| shadcn/ui 接入 | 组件只使用 `background`、`primary`、`muted`、`border` 等语义令牌，不在页面写固定颜色 |
| Electron 接入 | 主进程使用 `nativeTheme.themeSource` 同步系统、窗口、菜单和 Chromium 配色 |
| 主题包格式 | 使用带 `schemaVersion` 的声明式 JSON；浅色和深色令牌必须成对提供 |
| 安全边界 | 只接受白名单令牌，不允许主题包执行 JavaScript、注入任意 CSS 或引用远程资源 |
| 平台策略 | 桌面设置持久化到 `AppSettings`；PWA 偏好保存在当前浏览器，不反向修改桌面主题 |
| 兼容策略 | 未知主题、损坏主题或版本不兼容时自动回退默认主题，并给出 toast 提示和关键日志 |

## 主题包规范草案

```ts
interface ThemePackManifest {
  schemaVersion: 1
  id: string
  name: string
  version: string
  author?: string
  description?: string
  tokens: {
    light: ThemeTokens
    dark: ThemeTokens
  }
}
```

开放令牌分组：

- 基础表面：`background`、`foreground`、`card`、`popover`、`muted`、`accent`。
- 操作与状态：`primary`、`secondary`、`destructive`、`success`、`warning`、`info` 及对应前景色。
- 控件边界：`border`、`input`、`ring`。
- 导航与数据：`sidebar-*`、`chart-1` 至 `chart-5`。
- 风格参数：受限范围内的 `radius`、阴影等级、字体族枚举和信息密度枚举。

不开放任意选择器、布局尺寸、组件 DOM、动画脚本、网络字体和远程图片，避免主题改变功能结构或引入安全风险。

## 当前风险

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 页面仍存在固定颜色 | 某些区域在深色或自定义主题下不可读 | T2-C 建立扫描清单并逐页回归 |
| 主题令牌开放过多 | 用户主题可破坏布局和品牌识别 | 使用 schema 白名单与数值范围，不接受任意 CSS |
| 主题令牌开放过少 | 不同主题只有换色，缺少风格差异 | 在不改变布局的前提下开放圆角、阴影、字体和密度枚举 |
| Electron 与 Renderer 状态不同步 | 标题栏、菜单、弹层与页面明暗不一致 | 单一设置源，主进程与 Renderer 分别解析同一模式 |
| 主题包 schema 演进 | 旧主题导入失败或显示异常 | `schemaVersion`、兼容检查、迁移器和默认值回填 |
| 主题切换引发闪屏 | 冷启动体验不稳定 | 创建窗口前应用主进程主题，并在首屏脚本提前设置根类 |
| 应用内浏览器不可用 | PWA 360/768 自动截图暂时无法执行 | 修复 Browser 插件版本引用后补测，不使用未授权浏览器替代链路 |
| 当前缺少 macOS 环境 | 原生标题栏和系统主题无法真机确认 | 发布前在 macOS x64/arm64 各执行一次外部验收 |

## 维护规则

- 每个任务开始、阻塞、完成时更新状态、完成度和最近更新日期。
- 阶段完成度按其任务验收结果计算；专项总完成度按阶段权重计算。
- 进入 G1-G4 审核点时先提交方案或视觉结果，用户确认后再继续实现。
- 新增主题令牌必须同步更新 schema、默认主题、校验器、示例主题和测试。
- 主题相关缺陷记录在本文件，跨专项问题同步到 `docs/progress.md`。
