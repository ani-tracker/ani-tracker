## 目标范围

- 统一为 shadcn/ui 风格基础组件与设计令牌，减少页面级重复样式。
- 支持 Windows、macOS 桌面端，以及手机、平板、Android Web/PWA 场景。
- 采用响应式布局与平台适配层；下载、扫描、播放器等本地能力仍由桌面端承担。
- 覆盖 360、768、1024、1440 四档视口，兼容键鼠、键盘与触控操作。

## P4 安全基线

| 决策项 | 默认方案 |
| --- | --- |
| 网络绑定 | 默认固定监听 127.0.0.1；用户显式开启后仅监听 RFC1918 IPv4，不做公网映射 |
| 传输安全 | 局域网仅允许同源 HTTPS；稳定本地 CA 签发含当前私网地址 SAN 的服务端证书，裸 HTTP 仅限本机 |
| 设备授权 | 桌面端生成一次性配对码；每设备独立令牌、服务端存哈希并支持立即吊销 |
| 方法边界 | 使用显式注册表，不动态转发 IPC；完整设置、凭据、任意路径和删文件能力仅本地 |
| 请求防护 | 校验 Origin/Host，限制 64KB 请求体、频率和并发；日志不记录令牌、路径、URL 查询或参数 |
| 状态保存 | 仅保存令牌 SHA-256 摘要和设备元数据；凭据文件由 `safeStorage` 加密并原子替换，应用重启后无需再次配对 |

## 当前风险

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| MyAnime 页面职责过多 | 后续迭代易产生回归 | 按抽屉、表单和资源列表逐步拆分，不阻塞当前页面验收 |
| 桌面能力依赖 Electron IPC | Web/PWA 无法直接复用 | 先定义 AppClient 接口，再实现平台适配器 |
| 表格在窄屏信息过载 | 手机端可读性差 | 按字段优先级转卡片或渐进披露 |
| 多任务并行样式漂移 | 组件和交互不一致 | P1 先冻结令牌与组件 API，页面只消费公共组件 |
| Android 后台与下载限制 | 无法承担完整桌面能力 | Android 定位为远程管理端，核心任务留在桌面服务 |
| 移动系统需手动信任本地 CA | 首次接入有额外安装步骤 | 设置页展示 CA 地址、指纹和到期时间，并提供一键复制 |
| 缺少 macOS 与移动真机 | 无法完成 P5 全平台签收 | 保留为外部验收项，不用模拟器结果替代真机结论 |

## 维护规则

- 每个任务开始、阻塞、完成时更新状态、完成度和最近更新日期。
- 并行任务按“设计系统、应用壳、页面迁移、平台适配、测试”划分，避免多人同时修改同一页面。
- 阶段只有在全部验收项通过后才能标记为已完成。
